# DOCX 导出问题档案

本目录用于记录 DOCX 解析与导出问题的症状、根因、修复方式和回归验证，避免同类问题被重复修复。

## 记录原则

- 文件名使用 `YYYY-MM-DD-short-title.md`。
- 不提交客户原始 DOCX、错误导出 DOCX、截图或完整客户正文。
- 复现材料应使用脱敏后的最小 OOXML 示例；能够由自动化测试表达时，优先引用测试名称。
- 每次修复必须写明影响范围、失败策略和回归结果。
- 未完成验证的问题不得标记为“已解决”。

## 必填内容

每份问题记录至少包含以下部分：

1. 基本信息：日期、状态、影响范围。
2. 问题现象：用户可见症状和结构检查结果。
3. 最小复现：不含客户正文的复现条件。
4. 根因：具体到处理阶段和失效的数据结构。
5. 修复方案：正常路径、降级路径和失败策略。
6. 回归验证：自动化测试、真实结构验证及结果。
